YOUR FONT, PATCHED

Keep your mono. Add the icons.

Start with original font files and their license. The guided script handles family selection, patcher version, validation, and packaging.

Read the full setup instructions

  1. Get the project

    git clone https://github.com/voltaire-toledo/nerdified-fonts.git
cd nerdified-fonts

  2. Add your source files

    Place each unpatched family under fontsrc/FontName/, including its license. Nested folders are supported.

  3. Run the guided build

    ./scripts/patch_fonts.sh

    The host script can install dependencies on supported systems. For a container build, run docker compose run --build --rm patcher.

  4. Inspect and install

    Find fonts in patched/ and family/mode archives in releases/. Validate fonts before selecting them in your terminal. The script does not install fonts into your operating system.

Look at the joins

Box corners and vertical strokes should meet. These captures compare unpatched fonts in Programming Fonts. They show one browser preview, rather than a verdict on every platform or patched result.

Fallback fonts can change the result. Use the local font validator to compare glyph shapes and browser advances, then check the patched face in your actual terminal.

Keep the font licenses

The project’s scripts and documentation use MIT. Source fonts and Nerd Fonts glyph collections retain their own terms. Check whether a license permits distributing modified fonts before committing source files or sharing archives.
