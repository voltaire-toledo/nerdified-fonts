# Landing page specimen fonts

The landing page uses two small web fonts so the file list shows actual Nerd Font glyphs even when a visitor has not installed a patched font.

- `vt-nerd-mono-specimen.woff2` is a subset of the project's JuliaMono Nerd Font build. It contains basic Latin text and the folder, Python, Git, file, branch, and check glyphs used by the homepage. The original JuliaMono reserved font name was replaced for this derivative. JuliaMono is licensed under the SIL Open Font License; see `LICENSE-JuliaMono-OFL.txt`.
- `lekton-regular.woff2` and `lekton-bold.woff2` provide a distinct monospaced heading face. Lekton is licensed under the SIL Open Font License; see `LICENSE-Lekton-OFL.txt`.

The Nerd Font glyphs come from the pinned Nerd Fonts 3.5.1 glyph sources: Seti icons are from [Seti UI](https://github.com/jesseweed/seti-ui), language marks are from [Devicons](https://github.com/devicons/devicon), and file/status symbols are from [Octicons](https://github.com/primer/octicons). The corresponding MIT notices are included here.

The font subset was generated from the project's local patched JuliaMono build. The page only serves this reduced specimen; the complete font remains part of the local build output.
