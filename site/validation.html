Validate your fonts

Compare icon glyphs, box drawing, blocks, sextants, octants, and character advances side by side. Choose local TTF or OTF files. Your browser reads them locally; they are not uploaded.

Choose the font files you want to compare

Use Browse to select one or more patched TTF/OTF files, such as files under patched/. Choose faces that you want to compare (for example regular and Forced). Each comparison column is labeled using the selected filename; labels are not editable.

Select multiple files in the file picker with Ctrl-click or Shift-click (Cmd-click on macOS). You can add more files later; each selected face appears beside the others.

How to read these checks

Look first for the actual shapes. A blank, replacement box, or obviously different style can mean the selected font lacks that character or the browser silently used a fallback font. Browser APIs cannot reliably inspect a font’s full character map, so the visual sheet is a practical check, not a formal cmap audit.

Width is measured in browser pixels. Equal advances show that these characters take the same horizontal space in this browser. They do not guarantee the terminal counts a Unicode character as one cell. Terminal fallback, Unicode width tables, and rendering can differ; verify the final result in your terminal too.
