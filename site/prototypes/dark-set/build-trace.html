SOURCE / PATCH / FONT FILES

Patch a font family in three steps.

Bring a monospaced family. Run the Nerd Fonts patcher. Inspect the generated faces before installing them.

View the stepsOpen the font validator

  1. Choose a source family

    Use unpatched TTF or OTF files and include the font license.

    fontsrc/FontName/

  2. Run the guided build

    Select the family and patch mode in the script.

    ./scripts/patch_fonts.sh

  3. Inspect the output

    Find generated font faces in patched/ and archives in releases/.

    Compare glyphs in the validator
