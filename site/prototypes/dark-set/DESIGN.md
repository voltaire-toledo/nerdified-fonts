# Dark prototype set

## Design contract

Four layout studies for the Nerd Fonts patch workflow, sharing a graphite base and restrained yellow accents. The references inform layout and type scale, not copied branding.

- **Color:** warm graphite `#20242b`; panel `#282e37`; raised panel `#303741`; ink `#f0eee7`; muted text `#a8acb2`; rule `#4a515b`; marigold `#e3b83f`; burnt yellow `#bd842f`; cool blue `#91b5e8` for selected glyphs and links.
- **Type:** system sans for every heading; system sans for explanatory copy; local Nerd Font specimen for glyph samples; monospace for code and terminal rows.
- **Layout:** one familiar file-list specimen and the real patch workflow recur, while the four pages vary in composition: typographic poster, open motion-led story, monitor comparison, and linear build trace.
- **Signature detail:** show the source file view and patched view using identical filenames so the added Nerd Font glyphs are the clearest change. The centered `nerdified-fonts` hero mark is a PNG wordmark in the sample art's gold-and-blue pixel style.
- **Restrictions:** no light theme, mint/light green, purple, amber, or decorative counters. Avoid negative slogan contrasts. Keep motion brief, purposeful, and disabled for reduced-motion preferences.
