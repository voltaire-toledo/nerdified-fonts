FONT PATCH WORKFLOW

Three steps from source files to patched fonts.

  1. Choose a source family

    Add unpatched TTF or OTF files and the font license under fontsrc/FontName/.

  2. Run the guided patcher

    Select the family and patch mode.

    ./scripts/patch_fonts.sh

  3. Inspect the output

    Find generated faces in patched/ and family archives in releases/.

    Compare glyphs in the validator
