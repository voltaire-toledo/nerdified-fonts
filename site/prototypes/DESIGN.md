# Prototype design directions

These three static pages explore the same Nerd Fonts proposition: preserve a monospaced source font, then add recognizable glyphs and color to familiar file views.

## Shared elements

- Use the local Nerd Font specimen so the icon shapes are actual patched glyphs.
- Keep the project list, width comparison, and call to action consistent across variants.
- Keep copy compact and tied to the font patching workflow.
- Use visible keyboard focus and semantic section headings.

## Directions

| Page | Palette | Type | Layout |
| --- | --- | --- | --- |
| Quiet Specimen | Cool paper, graphite, cobalt | JuliaMono body; Lekton title; bold modern sans section headings | Split hero and restrained specimen panel |
| Night Console | Graphite, amber, blue | Monospaced body and headings | Dark TUI panel with thin rules, 1ch corners, restrained blue glow |
| Glyph Atlas | Neutral paper, cobalt, signal red | JuliaMono body; Lekton title; bold modern sans section headings | Glyph wall first, then the familiar file list |

These are review prototypes, not the production design contract. They intentionally share Nerd Font glyph content while varying color, typography, and information order.
