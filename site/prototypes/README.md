# Homepage design prototypes

Open `index.html` to compare three live pages side by side. Each prototype is a standalone static page and uses the local reduced Nerd Font specimen under `../fonts/`.

- `quiet-light.html`: cool paper and cobalt, mono body, Lekton title, bold modern sans section headings, split hero.
- `night-console.html`: graphite TUI palette, thin rules, 1ch corners, amber and blue glyph accents, monospaced headings.
- `glyph-atlas.html`: neutral field guide with cobalt and signal red, a larger glyph sampler, and an icon first layout; bold modern sans section headings.

All three use the same core story, file names, glyph samples, and width examples. The width rulers are illustrative. CSS constructs the interface; no image files are needed.
